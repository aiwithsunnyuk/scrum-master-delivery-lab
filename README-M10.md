# M10 · Agile Transformation & Operating Model

M10 extends the Delivery Lab from delivery leadership into organisational change.

## What it demonstrates
- Agile maturity assessment
- Systemic constraint diagnosis
- Target operating model design
- Transformation roadmap
- Coaching and change strategy
- Outcome-based transformation measures

## Apply
Overlay `app.py`, `README-M10.md`, the M10 data files and M10 docs into the existing repository. Keep all M1-M9 evidence.

Run with the existing working environment:

```bash
streamlit run app.py
```

Then open **Agile Transformation Lab** from the sidebar.

## Portfolio positioning
M10 completes the progression from Product → Scrum → Delivery → Leadership → Transformation.
