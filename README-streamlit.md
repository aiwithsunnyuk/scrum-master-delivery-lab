# Streamlit Presentation Layer

The Scrum Master Delivery Lab can be presented as an interactive portfolio.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Recommended recruiter flow
1. Executive Overview
2. 7-Milestone Journey
3. Delivery Dashboard
4. Impediment Center
5. Coaching Lab
6. Evidence Explorer

GitHub remains the source of truth for the underlying evidence.
