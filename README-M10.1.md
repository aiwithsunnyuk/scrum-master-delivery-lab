# M10.1 · Transformation Decision Simulator

M10.1 adds an interactive transformation judgement exercise to the Scrum Master Delivery Lab.

## What it demonstrates

- Diagnose before prescribing
- Select focused interventions
- Distinguish symptoms from system constraints
- Make consequences explicit
- Define an inspection signal
- Adapt based on evidence

## Apply

Overlay this package onto the existing repository. It preserves the M10 application and adds `Transformation Decision Simulator`.

No new Python dependency is required. The app continues to use the existing standard-library CSV reader and Streamlit environment.

## Practice loop

**Inspect → Intervene → Measure → Adapt**

The simulator is a transparent practice aid, not an AI hiring assessment.
