# Dependency Management

## Purpose

Make cross-team constraints visible early enough to allow sequencing, negotiation, ownership or escalation.

## Dependency flow

**Detect → Clarify need-by date → Identify owner → Assess impact → Agree response → Track → Escalate if needed → Close**

## Scrum Master stance

Facilitate coordination without becoming the permanent dependency owner. The goal is to improve the system so teams can resolve dependencies with increasing autonomy.
