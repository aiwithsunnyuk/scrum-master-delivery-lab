# Executive Status Brief

## Five-part structure

1. **What changed?** State the evidence.
2. **Why does it matter?** Connect it to outcome, scope, quality or timing.
3. **What is being done?** Name owner and response.
4. **What decision/support is required?** Make the ask explicit.
5. **When will we inspect again?** Close the loop.

## Example

**Signal:** Release readiness is at 75% because one critical dependency remains unresolved.

**Impact:** The dependency threatens the planned integration window.

**Action:** Engineering and the dependency owner have agreed a recovery path.

**Ask:** Confirm whether the fallback sequencing is acceptable if the dependency misses its target.

**Next inspection:** Dependency review at the next delivery checkpoint.
