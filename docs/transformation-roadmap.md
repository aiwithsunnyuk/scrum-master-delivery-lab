# Transformation Roadmap

| Phase | Focus | Example outcome |
|---|---|---|
| 1. Assess | Establish evidence baseline | Shared view of current constraints |
| 2. Align | Agree accountabilities and success measures | Explicit operating principles |
| 3. Pilot | Test one or two systemic changes | Observable behaviour change |
| 4. Measure | Inspect outcome, flow, quality and stakeholder signals | Evidence of impact |
| 5. Scale | Replicate proven practices selectively | Consistent patterns across teams |
| 6. Sustain | Embed coaching, governance and inspection | Continuous improvement becomes normal work |

Avoid a transformation plan that is only a calendar of ceremonies. Each phase needs a hypothesis, owner, evidence and inspection point.
