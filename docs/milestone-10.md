# Milestone 10: Agile Transformation & Operating Model

## Objective
Move the portfolio from managing delivery signals to improving the system in which delivery happens.

## Transformation model
`Assess → Diagnose → Design → Align → Pilot → Measure → Scale → Sustain`

## Evidence created
- Agile maturity assessment
- Current-state pain-point map
- Target operating model
- Transformation roadmap
- Coaching and change strategy
- Outcome measurement

## Scrum Master stance
The Scrum Master does not own organisational transformation alone. The role is to surface systemic constraints, facilitate alignment, coach behaviours, enable experiments, and make outcomes visible.

## Interview message
A strong transformation response starts with evidence and system conditions, not with introducing more ceremonies or tools.
