# Definition of Ready

A Product Backlog Item is considered ready for Sprint Planning when the team has enough shared understanding to forecast it responsibly.

Checklist:

- [ ] User/customer value is clear.
- [ ] Acceptance criteria are testable.
- [ ] Dependencies are identified.
- [ ] External decisions are identified.
- [ ] UX/design inputs are available when required.
- [ ] Technical questions are sufficiently understood.
- [ ] Item is small enough for a Sprint.
- [ ] Product Owner is available for clarification.

**Important:** Ready is a team working agreement, not a bureaucratic approval gate.
