# Milestone 10.1 · Transformation Decision Simulator

## Purpose

M10.1 turns the Agile transformation model into a practical decision exercise. The candidate starts from observable system evidence, selects a first intervention, inspects the likely consequence, and identifies the next signal to review.

## Decision model

**Inspect → Intervene → Measure → Adapt**

The simulator deliberately includes weak, mixed and strong choices. It is transparent practice tooling, not an AI hiring score.

## Capability demonstrated

- Systems thinking
- Evidence before prescription
- Decision ownership
- Small, focused interventions
- Metric literacy
- Dependency and governance judgement
- Inspection and adaptation

## Interview use

A strong response should explain **why** the selected intervention addresses the constraint, what consequence is expected, and what evidence would cause the Scrum Master or Agile leader to continue, change or stop the intervention.

## Portfolio principle

The simulator is intentionally not a generic Agile quiz. It uses themes already demonstrated in the portfolio: stakeholder bypass, dependency management, metric misuse, decision latency and systemic coaching.
