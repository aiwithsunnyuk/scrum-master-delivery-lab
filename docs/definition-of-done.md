# Definition of Done

A Product Backlog Item is Done only when the team's agreed quality criteria are satisfied.

- [ ] Code implemented.
- [ ] Peer review completed.
- [ ] Automated tests passing.
- [ ] Functional testing completed.
- [ ] Acceptance criteria satisfied.
- [ ] Security/compliance checks completed where applicable.
- [ ] Documentation updated where required.
- [ ] Deployable Increment produced.
- [ ] Product Owner acceptance confirmed where part of the team's agreement.

The Definition of Done is intentionally stronger than "development complete."
