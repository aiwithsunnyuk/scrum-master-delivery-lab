# For Recruiters and Hiring Managers

## Why this repository matters

This repository is designed to make practical Agile delivery capability easy to inspect.

It complements professional experience with tangible examples of:

- Scrum facilitation
- Product Backlog refinement
- Sprint execution
- Impediment removal
- Dependency management
- Metrics and transparency
- Stakeholder facilitation
- Coaching
- Retrospectives
- Continuous improvement

## Positioning

The portfolio should be read alongside the candidate's professional experience and certifications. The scenarios and metrics are synthetic and are included to demonstrate practical application, not to represent confidential client work.
