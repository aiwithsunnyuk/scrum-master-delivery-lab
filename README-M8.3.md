# M8.3 · Executive Recruiter Mode

M8.3 adds a recruiter-facing presentation mode to the Streamlit presentation layer.

## Purpose

Turn the portfolio into a concise 3-minute executive walkthrough:

1. Position the Scrum Master capability.
2. Show the M1-M7 delivery system.
3. Prove capability with selected evidence.
4. Demonstrate judgement through an M8.2 interview scenario.

## Local setup

Use the same virtual environment already created for M8.1/M8.2.

```bash
cd ~/Downloads/scrum-master-delivery-lab
source .venv/bin/activate
streamlit run app.py
```

Do not reinstall PyArrow if the existing environment already works.

## Recommended recruiter flow

**Executive Recruiter Mode → 7-Milestone Journey → Delivery Dashboard → Evidence Explorer → Interview Simulation**

The repository remains the source of truth. Streamlit is only the presentation layer.
