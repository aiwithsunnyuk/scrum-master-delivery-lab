# M9 — Delivery Leadership & Transformation Lab

M9 adds an executive delivery layer to the Scrum Master Delivery Lab.

## What it demonstrates

- Release readiness
- Delivery risk management
- Cross-team dependency management
- Agile governance
- Executive status communication
- Decision traceability
- Transformation coaching

## Run

Use the same environment as M8.3.1. No new Python dependency is required.

```bash
streamlit run app.py
```

Then open **Delivery Leadership Command Center** in the sidebar.

## Design principle

The Streamlit page is a presentation layer. Evidence remains in Markdown and CSV files so the repository continues to be the source of truth.
